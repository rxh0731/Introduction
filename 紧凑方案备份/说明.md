# 紧凑方案源码备份

备份日期：2026-10-29。此目录保存取消方案二之前的完整源码及配置，供以后恢复或提取紧凑排版实现使用，不参与当前程序运行和打包。

- `main.py`：完整原始源码，同时包含原方案一和方案二。
- `参数设置.json`、`参数设置1.json`：修改前的配置，`scheme` 为界面索引，0 表示方案一、1 表示方案二；运行时传入渲染器的值分别为 1、2。
- `requirements.txt`、`requirements.lock.txt`：原依赖及版本记录。
- `build_portable.ps1`、`启动经文排版.bat`：原构建与启动脚本，仅作记录；需要使用时应回到项目根目录并确认路径，勿直接在备份目录打包。

紧凑实现的主要入口：

1. `layout_body(..., capacities=...)`：前两列采用较短容量，之后采用完整正文列容量。
2. `Preview.draw_layout` 中的 `scheme == 2` 分支：标题数量决定上部大田字格数量，下部画两列标准小格，正文先填充右下短列，再填左下短列及其余完整列。
3. `export_layered_psd` 中的编号分支：标题组 0，正文按照紧凑区域的阅读顺序编号。
4. `MainWindow` 中的排版方案控件及配置读写。
