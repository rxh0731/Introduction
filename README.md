# 经文排版程序

基于 PySide6 的中文竖排版面工具。标题、正文、尾题拥有独立网格参数，支持电脑字体和文字图片字库、版面预览、打印以及 PNG、JPG、分层 PSD/PSB 导出。

## 运行

在项目自己的虚拟环境中安装 `requirements.txt`，执行 `python main.py`，或使用 `启动经文排版.bat`。启动时自动读取项目工作目录中的 `参数设置.json`，也可以在界面中保存参数。

- 阅读方向：从右向左、从上到下。
- 第一段为标题；首个以 `*` 开头的段落开始尾题区域。
- 独立一行的 `#` 触发分版，默认间距 25 毫米；连续标记累计间距。
- 空格占格，空行空一列。

## 文字图片字库

在“整体 → 文字来源与图片字库”中选择“文字图片（字库）”，指定目录后点击“刷新预览”。递归扫描子目录，支持 PNG、JPEG、TIFF、PSD、PSB、GIF、BMP、WebP 等图片。GIF、TIFF 等多帧图片读取第1帧，PSD/PSB 读取完整合成图；保持原始图像颜色和透明度。

- **首字匹配**：`佛2.png`、`佛10.tif` 等归为同字字形，按文件名自然顺序固定轮换。刷新、打印、导出使用相同顺序。
- **段落编码**：严格使用 `1.1.png`、`2.3.psd` 等名称。标题为第1段，空行和独立的 `#` 不计段号；尾题段首 `*` 不计字序，半角及全角空格计字序。编码独立于视觉列号。重复编码选排序第一项，并在检查记录中提示。
- **对齐**：保留完整图像边界居中，或先裁去透明/白色空白边缘再居中。各区域文字偏移仍然有效，字库源文件不被修改。
- **原图尺寸模式**：物理尺寸=像素尺寸÷源 DPI×25.4，缺少有效 DPI 时按300。全局缩放默认100%；自动缩放默认开启，占格比例取宽、高占格比例较大值；≤75%放大到95%，≥150%缩小到95%。先应用全局比例，再判断自动缩放。
- **相对单元格模式**：按所在区域单元格等比适配，默认95%，不使用原图 DPI 或全局/自动缩放。
- 缺少图片、损坏图片或完全空白图片保留空单元格，不使用字体补字；“查看匹配记录”可以查看、保存索引、缺图及异常详情。
- 各图片参数自动纳入“参数保存”。字体模式继续使用原有字体、字号；字库模式停用这两类控件。

PNG/JPG、预览和打印共用摆放结果；PSD/PSB 中每张匹配图片为一个无蒙版的独立像素图层，保留现有分组、编号与网格/白底图层规则。

## 便携版

当前电脑字体版本的单文件程序保存在 `电脑字体最终版/经文排版程序.exe`。后续构建使用项目自己的 `.venv`，通过 PowerShell 7 执行 `build_portable.ps1`，输出至 `便携版` 目录。

构建脚本限制 DLL 搜索路径，避免引入外部 Poppler/ICU 和其他 Qt 环境。虚拟环境、构建缓存、日志和自动化测试输出不纳入 Git。

## 测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`ui_mockups` 保存界面设计原型；`紧凑方案备份` 保留已停用的紧凑排版代码供参考。`电脑字体最终版` 中的 EXE 为此前保留的电脑字体版本，新字库功能通过当前源码运行。
