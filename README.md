# 经文排版程序

基于 PySide6 的中文竖排版面工具。标题、正文、尾题拥有独立网格参数，支持电脑字体、版面预览、打印以及 PNG、JPG、分层 PSD/PSB 导出。

## 运行

在项目自己的虚拟环境中安装 `requirements.txt`，执行 `python main.py`，或使用 `启动经文排版.bat`。启动时自动读取项目工作目录中的 `参数设置.json`，也可以在界面中保存参数。

- 阅读方向：从右向左、从上到下。
- 第一段为标题；首个以 `*` 开头的段落开始尾题区域。
- 独立一行的 `#` 触发分版，默认间距 25 毫米；连续标记累计间距。
- 空格占格，空行空一列。

## 便携版

当前电脑字体版本的单文件程序保存在 `电脑字体最终版/经文排版程序.exe`。后续构建使用项目自己的 `.venv`，通过 PowerShell 7 执行 `build_portable.ps1`，输出至 `便携版` 目录。

构建脚本限制 DLL 搜索路径，避免引入外部 Poppler/ICU 和其他 Qt 环境。虚拟环境、构建缓存、日志和自动化测试输出不纳入 Git。
